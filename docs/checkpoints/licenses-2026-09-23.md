# Offline license and attribution audit — 2026-09-23

## Findings and changes

Previously the mod archive carried only the project's GPLv3 text, and the
symbols archive and staging target omitted dependency notices. Both archives
and staging now carry `LICENSE`, `THIRD_PARTY_NOTICES.md`, and `licenses/`.
The explicit license inventory drives CMake packaging and staging; archive
manifests hash the shipped copies. Missing notice files or destination
collisions fail before replacing existing archives.

The [notices](../../THIRD_PARTY_NOTICES.md) identify CommonLibSSE-NG, spdlog,
bundled fmt, rapidcsv, JSON and its embedded components, the menu wrapper and
ImGui/cimgui declarations, and the Community Shaders reference. License texts
were taken from the pinned dependency checkout or upstream source; the
[inventory](../../licenses/inventory.json) records origins and hashes.

The three vendored headers match the upstream files byte for byte: JSON
v3.12.0, menu framework `c97cdce6dd207c7cf1401611bc82bd7e8f97a814`, and CS
`dd2677fc4020db1da91b39cebef3dbfbe8913983`. The menu revision's GPLv3 license
matches the root license byte for byte. Community Shaders' separate exception
text is retained with its COPYING file; the pinned README supplies the scope
of Modded Code and Modding Libraries. This pass changes no project license.

Presenter textures are generated black pixels. The explicit binary archives
exclude game-record fixtures, game texture files, peer DLLs, fonts and CS
logos. The EFSH fixtures remain useful source-test inputs with unresolved
publication provenance. No files in `reference/` or `decompiled/` were changed
or added to the binary package.

## Verification

- License inventory: two checks cover notice/header hashes, inventory
  completeness, and CMake dependency pins without requiring fetched source.
- Packaging: six regression checks cover both archives' notice content,
  missing/conflicting notices without output replacement, deterministic
  output, stale-input exclusion, manifest hashes, and tampering.
- Built the Windows candidate with `package-candidate`; both archives passed
  integrity verification. The local stage target was checked separately.
  Candidate `6ed2f3a0692e-85e07d675bcc35ab-Release` contained 1,046 mod payload
  files and 15 symbols payload files (excluding each manifest); all 14 shared
  notice files in each ZIP and local staging matched the source bytes.
- No in-game testing, installation into MO2, or source/release publication.

## Remaining publication work

1. Freeze the release source and deliver matching corresponding source,
   including dependency sources and build/install scripts, through a reviewed
   GPL distribution arrangement. The current dirty candidate and repository
   remote alone do not establish that delivery.
2. Review the first-party GPL linking/exception policy for the Skyrim/SKSE
   combination. CS's exception applies to its covered material; copying it
   into notices does not grant the same permission for this entire project.
3. Establish provenance and redistribution suitability for game-derived test
   records and other reference inputs intended for source publication.
   Exclusion from mod archives does not settle source-tree distribution.
4. Resolve the menu header's unrecorded cimgui generator revision. Its
   upstream tree identifies Dear ImGui 1.90.8 docking. The included cimgui MIT
   notice is an explicitly identified attribution supplement, not proof of
   that generator's exact revision.

JSON's amalgamated SPDX labels and upstream component descriptions differ
for Hedley and Abseil. Both relevant license texts are retained, and the
discrepancy is recorded in the notices instead of treating every embedded
component as solely MIT.
