## 1. How the engine works today

**Frame flow.** `PlayerCharacter::Update` calls `Manager::OnFrame` on the main thread (`engine/Hooks.cpp:20-23`). `OnFrame` (`engine/ManagerTick.cpp:858-933`) runs these in order:
1. Returns early while loading (872).
2. `AdvanceRegressionRun`.
3. `FlushMetricsHeartbeat` once a second (878-880). This samples video memory, runs the whole budget through `UpdateBudget` and emits the heartbeat (816-833).
4. Resets `frameSyncs_`.
5. `RunWaitingInstalls` (883, 1078-1098), which calls `applications_.SyncNow` synchronously.
6. `FireDueFinalizes` (equip settle).
7. The once-a-second sweeps.
8. `MarkWaitingStale` and `MarkRecheckStale` on their timers (898-905, 935-951).
9. On the tick interval: `DrainPlanJobs` (910), then `Tick` only when `!live_.empty()` (917-923), then mesh sweep, `PublishSnapshot` and `ObserveRegression`.

**The tick.** `Manager::Tick` (955-1022):
- First `AdvanceResizes`: swap and start resizes (1196-1227).
- Then a loop over `live_`. An actor without 3D is forgotten (973-979). Otherwise the loop runs `ClaimLostGeometries`, ticks signals, sets `inView`/`screenFraction` (993-994), runs `ReleaseWhileHidden` and `RequestLevelStep`, renders when in view, updates lights, and calls `FinishApplications`.
- Last, `DrawHidden` draws the first draws and resizes in pacing order (1024-1054), and `AttachFirstDraw` ends a first draw (1056-1076).

**Where sync runs: outside the tick, in SKSE tasks.** Every stale mark goes through `SessionQueue::SubmitSync` (`engine/SessionQueue.cpp:132-190`), which posts a task. The task calls `ApplicationService::RunActor` (`ApplicationService.cpp:171-183`). `RunActor` begins a per-actor application record (`BeginActor`) and calls `apply_`, which is `Manager::SyncStale` (`Manager.cpp:28-33`). `SyncStale` (`ManagerApply.cpp:1160-1177`) then:
- calls `SyncActor`: decide, defer, record the sync log, retire, install (1195-1260);
- calls `ReconcileAnimationEvents`;
- calls `PrepareApplications(tokens)` unless the sync was deferred;
- charges `frameSyncs_`.

**What triggers a sync:**
- Equip events, actor-loaded events and node updates (`Events.cpp:31-33,48,99`).
- The regression apply request (`RegressionRequests.cpp:187`).
- `MarkReinstall` from `ChangeAndRebuildActors` (`ManagerApplication.cpp:191`).
- The equip finalize, 100 ms after an equip (`SessionQueue.cpp:192-227`).
- Recheck timers, radius shrink (`ManagerTick.cpp:1409`) and claims (1578).

`QueueForget` posts `AbandonApplications` + `ForgetActor` directly (`Manager.cpp:74-82`). So do `RetireAll` (`ManagerAnimation.cpp:11-24`) and the regression retire (`RegressionRequests.cpp:175-181`).

**Where state lives** (`Manager.h:290-336`):

| State | Holds |
|---|---|
| `live_` (`LiveActor`, `LiveActor.h:128-149`) | Resources plus the lifecycle fields `inView`, `screenFraction`, `appliedResolution`, `resize`, `firstDraw`, `levelCosts`, `intermediates`, `stepUpBlockedFrom`, `smallSinceMS`, `hiddenSinceMS`, `awaitedPlan`, `renderedFrame` |
| `tracked_` (`TrackedActor`, 303-308) | Sync `state`, `models`, `targetResolution`, `returnBytes` |
| `budget_`, `budgetRadius_`, `waitingInstalls_`, `syncLog_`, `frameSyncs_` | The budget, the radius, the waiting installs, the sync log, per-frame sync cost |
| `lastWaitingCheckMS_`, `lastRecheckMS_`, `lastTickMS_`, `lastMetricsMS_` | Timers |
| `planJobs_`, `planQueue_`, `renderPlans_` | Plan jobs and the plan cache |
| `applications_` | Application tokens |

**Plan jobs.** `DrainPlanJobs` (`ManagerApply.cpp:1546-1595`) closes the job in the book, stores built plans in the cache, then walks `live_` with `StepFor` and calls `RebuildAwaitedRender` (1597-1621) or `FailAwaitedRender` (1623-1630).

## 2. The new engine shape

**What `Manager` owns after R4:**

Deleted from `Manager`: `tracked_`, `budget_`, `budgetRadius_`, `waitingInstalls_`, `syncLog_`, `frameSyncs_`, `lastWaitingCheckMS_`, `lastRecheckMS_`.

**Frame flow.** `OnFrame` keeps the lab start, the loading return, the regression run, the finalizes, the gesture, the frame count and the sweeps. It drops `RunWaitingInstalls`, `MarkWaitingStale` and `MarkRecheckStale`. On the tick interval it calls `Manager::RunTick(now, settings)`. `RunTick` runs **with or without `live_` entries**, because installs now happen only inside the tick; the `!live_.empty()` guard at `ManagerTick.cpp:917` goes.

`RunTick` steps:
1. `std::vector<PlanJobDone> jobs = DrainPlanJobs()`: the engine half only (close, cache, trace).
2. Compositor `BeginTick`, sweeps.
3. `TickFacts facts = GatherFacts(now, settings, std::move(jobs))` (section 3).
4. `CheckAgreement(world_, facts)` (section 5).
5. `TickOutput out = Orchestration::Tick(std::move(world_), facts); world_ = std::move(out.world);`
6. `EmitCoreRecords(out.trace, out.logs)`: `Trace::EmitSafely` per record, `logger::info`/`warn` per log line.
7. `lab->RenderPreviews`, `SetGeneratedShaders`, `BeginTimedTick`.
8. `results_ = Execute(out.commands, tickContext)`: one `Match` per command, in order.
9. `EndTimedTick`.
10. If `heartbeatDue_`: `EmitHeartbeat(...)`, which reads `world_` const and `live_` (section 7).

## 5. The per-actor resource store and the agreement check

**`LiveActor` after R4** keeps:
- `actor`, `catalog`, `matches`, `pieces`, `instances`, `placements`;
- `applications` (tokens awaiting finish) and `fullSizes`;
- `std::optional<ResizeInFlight> resize`: `ResizeProgress` shrinks to `to`; `from` and `beganFrame` live in the core;
- `std::optional<FirstDraw> firstDraw`, holding only `slots`;
- `std::optional<JobId> awaitedPlan`;
- `IntermediateHolding holding`: the attached render's real holding, set by `ReleaseIntermediates` and by `TickActor{drawStacks}`. `RenderInstance` has no query for it (`render/RenderInstance.h:50`).
- `ResolutionLevel renderLevel`: the level the attached render was built or swapped at.

It removes `inView`, `screenFraction`, `appliedResolution`, `levelCosts`, `intermediates`, `stepUpBlockedFrom`, `smallSinceMS`, `hiddenSinceMS`, `renderedFrame`, the `LiveResize` variant, and `FirstDraw::beganFrame`/`drawTicks`.

`models_` replaces `TrackedActor::models`. Bindings, shells, lights, merged slots and placements are unchanged.

**Agreement check, pure part.** `orchestration/Agreement.h`:

```cpp
struct UnpublishedCount { std::size_t total; std::size_t drawn; };
struct HeldRender { ResolutionLevel level; IntermediateHolding holding; };
struct HeldResize { ResolutionLevel to; UnpublishedCount draw; };
struct HeldResources {
  std::optional<HeldRender> render; std::optional<UnpublishedCount> firstDraw;
  std::optional<HeldResize> resize; std::optional<PlanJobId> awaited;
};
struct Disagreement { ActorId actor; std::string what; };
[[nodiscard]] std::vector<Disagreement>
Disagreements(const World &, const std::map<ActorId, HeldResources> &);
[[nodiscard]] World SettledWorld(const World &, const TickFacts &);
```

Every phase other than `Planning` also requires no awaited plan job.

Comparisons:

| Core state | The store must hold |
|---|---|
| No record, or no `render` | No entry. An entry here is "a render the core does not track" (REFERENCE 3330-3332). |
| `Empty` | No render, no resize, no first draw, no awaited job. The entry may be absent. |
| `Planning{job}` | `awaited == job`; no render, first draw or resize. |
| `Drawing{level, draw}` | A render at `level`; first draw `total`/`drawn` equal; no resize. |
| `Shown{level, intermediates}` | A render at `level`; no first draw; no resize; same holding. |
| `Queued{resize}` | A render at `resize.from` with the same holding; no resize. |
| `Running{resize, draw}` | A render at `resize.from` with the same holding; a resize to `resize.to` with equal `total`/`drawn`. |

Tests can reuse `tests/orchestration/sim/Shell.h`: map each `EngineActor` to `HeldResources` and assert no disagreement over the R3 scenarios.

**When it runs.** At the start of `RunTick`, after gathering facts and before `Tick`. It compares `live_` (after last tick's commands ran) with a shadow world:

`World settled = SettledWorld(world_, facts);` (`RecordSyncResults`, then `RecordRenderResults` with the jobs removed from the facts).

Both steps are public in `Tick.h:20-23`. At that point both sides describe the same moment: every decision of the last tick has executed, and its results are recorded. The shadow's trace output is discarded.

**On disagreement** (no crash, no repair):
- A `Trace::Event::kMetrics` record `{action: resource_disagreement, actor, phase, what}`, emitted only when an actor's set of disagreements changes, to avoid a per-tick flood.
- A `LogOnce` warning.
- A running count written as `resource_disagreements` on the `target_holders` heartbeat (`TargetCensus.cpp:165-171`).

## 6. Sync and application integration

**`ApplicationService` and `SessionQueue` are unchanged.** Event threads, coalescing, generations and token revisions keep working. What changes is the `apply_` callback (`Manager.cpp:30-33`): it becomes `NoteStale(id, tokens)`, which only stores `stale_[id] = tokens` (latest wins). It runs on the main thread, so it needs no lock.

| Today | R4 |
|---|---|
| `MarkStale` (events, regression apply, `MarkLoadedActorsStale`) | Unchanged path; arrives as `StaleActor` next tick |
| `MarkWaitingStale`/`MarkRecheckStale`, `RunWaitingInstalls`/`SyncNow`, radius-shrink `MarkStale`, claim `MarkStale` | The core's `Observe`; the executor calls `SyncNow`, then the actor arrives in `stale_` |

| `QueueForget` (unload event), `RetireAll`, failed `MarkReinstall` (`ManagerApplication.cpp:192`), regression retire | `forgets_`, and the next tick's `Forget` (Q2). Actors not in `world_` (only `animations_` or tokens) get the non-core cleanup (`animations_.Stop`, `AbandonApplications`) directly. |

## 10. Decisions (each recommendation taken)

- **Q1. When to check agreement.** Recommend the settled shadow at tick start (section 5) over a post-execution check with tolerated windows. It costs one `World` copy and two cheap steps per tick, and needs no exceptions.
- **Q2. Forget requests.** There is no `TickFacts` field for "forget this actor". Options:
  - (a) Report `loaded3D=false`. This is false for `RetireAll` and the regression retire.
  - (b) Add `std::vector<ActorId> forgets` to `TickFacts`, handled in `ForgetUnloaded`. This is an R0 header change made by the main session.

  Recommend (b), for explicitness and testability.
- **Q3. Stale plan jobs.** Recommend reporting them as `PlanJobBuilt`: the awaiter rebuilds and resubmits, as `StepFor` does today. The alternative is a `PlanJobDropped` contract change.
- **Q4. Install level choice in R4.** Deleting `InstallLevelChoice` forces this. Recommend switching to R7a's `RenderBuildAt`/`LevelCostsOf` (`planners/InstallProgram.h`) in R4; it also yields `Installed::levelCosts`. Delete `ChooseInstallLevel`, `LevelCostOf` and `CachedLevelCost` in R4 rather than R7b, and update the Open line.
- **Q5. Claims.** Recommend detecting them and retiring the lost geometry at gather time. That is an observation of ownership already lost, with no decision. The alternative is doing it in `TickActor` and reporting next tick. Record it in REFERENCE as the one resource change outside a command.
- **Q6. Forget and applications.** Recommend that `Forget` always runs `AbandonApplications`, as the unload and `QueueForget` paths do today. Cost: when `Advance` forgets an actor, its token problem reads "retired before rendering completed", not "no applicable loaded geometry". The phase stays `kUnmatched` either way.
- **Q7. Sync cost metrics.** Recommend keeping `sync_us` as a sub-measure and changing `regression_budgets.py` to `plugin_us = frame_us`, with a REFERENCE note.
- **Q8. Clock.** Recommend a wrap-safe 64-bit accumulator over `NowMS()` for `TickFacts::now`.
- **Q9. `estimated_bytes`.** Recommend the World estimate plus the new `engine_estimated_bytes`.
- **Q10. Install log wording.** `Install` carries `InstallKind`, not `SyncKind`, so "changed" becomes "reinstalled" in `ReportSummary` (`ManagerApply.cpp:1099-1108`). Recommend accepting this, a log-only change.
- **Q11. Dead planners** (`SmallSince`, `NextLevelStep`, `ResizeIdle`/`ResizePending`, the one-argument `MayDrawStack`). Recommend deleting them in R4 with their tests.
- **Q12. Swap conceal.** Recommend always concealing (removes an executor branch on sight).
- **Q13. Disagreement severity.** Recommend trace plus counter in R4; decide at R6 whether a disagreement fails a regression case (the ownership plan's D8 is not on this branch).
- **Q14. Naming.** Recommend keeping `LiveActor` and `live_` in R4, and doing a separate `tools/rename.py` pass to `ActorResources` later if wanted.
- **Q15. A failed swap and the agreement check.** The store keeps a resize that did not swap until the `AbandonResize` that `ResizeNotSwapped` implies runs, one tick later. `SettledWorld` therefore leaves `ResizeNotSwapped` out (a core change with a native test, aed8953). The alternative was an executor that drops the resize itself, which would duplicate the core's abandon.
- **Q16. Heartbeat cadence.** The tick drains the metrics and takes the sample; `OnFrame` emits the heartbeat after its frame timer, as before R4 (`RunFrame` returns a `HeartbeatReading`). A regression window edge (`FlushMetricsHeartbeat`) emits at once and gives its sample to the next tick's `TickFacts::memory`.
- **Q17. Model pinning time.** `KeepModels` uses the gather's observation time (`GatheredFacts::observedAtMS`), not the execution time. `KeepModels` drops every model not seen at exactly that time, so a later clock would drop the models observed in the same tick.
- **Q18. Executor results without resources.** `Install` reports `InstallFailed` when the actor lookup or `LiveActorFor` fails, and `InstalledWithoutRender` when nothing is placed. `BuildAwaitedRender` reports `InstalledWithoutRender` with a disagreement when no entry exists, and without one when the actor handle is gone, so the core never waits on a plan the engine dropped. Executor disagreements trace `resource_disagreement` with a `command` field; the agreement check uses a `phase` field. `resource_disagreements` counts both and is not reset on load.
- **Q19. `resolution_swap`.** The trace loses `frames`, because the frame a resize began lives in the core. No tool reads it.
- **Q20. `PlannedBytesOf(const LiveActor &)`.** Deleted, not kept: `engine_estimated_bytes` comes from the heartbeat's `PlannedTargets`, which needs only `HeldNow` and `InstancesOf`.
- **Q21. Dead planner tests.** The `NextLevelStep` and `SmallSince` tests became `LevelStepOf` tests with a test-local hold, and the one-argument `MayDrawStack` tests use the budget argument, so the step rules keep their coverage. The `HiddenSince` tests are deleted; the core's `Hold` tests cover the delay.
- **Q22. Regression retire.** `RegressionRequest::retireTicks` counts the ticks `ObserveRegression` waited; the retire passes once the actor has no forget request, no store entry and no core record, and fails after 10 ticks.
