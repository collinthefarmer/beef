# Per-row author notes (2026-09-21)

Gate-5 (a format-1 change before the freeze) and UI backlog item 16. An
author annotates a row — a signal, source, mask, layer, or output — with
free text, so another author reading the recipe understands it. The note
is author documentation, distinct from our tooltips.

## Data

The note lives on the record, not in a recipe-level map, so it moves with
the row and survives reordering. `std::string note;` on each annotatable
record, empty when absent:

| Record | JSON today | Note carrier |
|---|---|---|
| `Signal` | object (kind key + `curve`) | add a `"note"` key |
| `Source` | object (one kind key) | add a `"note"` key |
| `Layer` | object | add a `"note"` key |
| `SurfaceOutput`, `LightOutput` | object | add a `"note"` key |
| `Mask` | **bare string** (the expression) | dual form (below) |

Curves are string-valued like masks and were not in the author's list;
they follow masks trivially if wanted.

## Increments

1. **Object-valued rows** — LANDED 2026-09-21. `note` on `Signal`,
   `Source`, `Layer`, `SurfaceOutput`, `LightOutput`. Parse reads an
   optional `"note"` (`RecipeRead.cpp`), serialize omits it when empty
   (`RecipeWrite.cpp`, `WriteTextIf`), the schema allows it (a `note`
   `$def`, added to the signal/source/layer/output objects), and a
   round-trip test asserts each note survives and an empty note is
   omitted (`recipe_tests.cpp`). Covers signal, source, layer, output
   from the list.
2. **Masks and curves** (string-valued) — LANDED 2026-09-21. A mask or
   curve value becomes a dual form: a bare expression string (unchanged,
   no note) OR `{ "expr": "<expression>", "note": "<text>" }`, idiomatic
   beside the `av`/`distance` dual forms and backward-compatible. `Mask`
   and `Curve` gain `note`; a shared `NotedExpression` parse helper and a
   `NotedExpressionToJson` serialize helper cover both, the schema adds a
   `annotatedExpression` `$def` the masks/curves objects reference, and
   the round-trip test asserts the note survives and a note-free row
   stays a bare string.
3. **The shared inspector field** (backlog 16): one reusable note
   `FormField` every inspector form appends the same way (`SignalForm`,
   `SourceForm`, the layer and output forms), rendered by
   `menu/FormDraw.cpp`, bound to a `SetNote`-style edit per subject. Not
   a text box hand-added per inspector — the "consistent home".
